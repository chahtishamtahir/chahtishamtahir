### 🚌 MyCampusRide — Real-Time Campus Bus Tracking System

![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat-square&logo=mongodb&logoColor=white)
![Express.js](https://img.shields.io/badge/Express.js-000000?style=flat-square&logo=express&logoColor=white)
![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=node.js&logoColor=white)
![Socket.io](https://img.shields.io/badge/Socket.io-010101?style=flat-square&logo=socket.io&logoColor=white)
![Leaflet](https://img.shields.io/badge/React_Leaflet-199900?style=flat-square&logo=leaflet&logoColor=white)

</div>

A full-stack web application that allows students to track their campus buses in real time, built as my Final Year Project.

- 🗺️ **Live GPS tracking** using Socket.io and React Leaflet
- 🔐 **Role-based portals** for Students, Admins, and Drivers
- 💳 **Fee payment flow** — receipt submission with admin approval
- 📱 **Responsive UI** built with Material UI
